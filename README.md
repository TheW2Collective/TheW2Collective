# The W2 Collective

**Software studio in Funchal, Madeira, Portugal.** We build the software local businesses run on: websites that take bookings and payments, management dashboards, apps for teams and customers, and custom internal systems.

We build it first. You see a working version made for your business, and you only pay if you like it. One agreed price, no monthly fee, and the domain, the software and the data stay in your name.

**Estúdio de software no Funchal, Madeira.** Fazemos o software com que os negócios da ilha trabalham: sites com reservas e pagamentos, software de gestão à medida, apps para a equipa e para os clientes e sistemas internos. Fazemos primeiro e mostramos a funcionar antes de pagar.
